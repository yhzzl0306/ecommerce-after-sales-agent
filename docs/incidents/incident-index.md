## 复盘原则

1. 先独立验证 FastAPI 接口，再判断 Dify 节点问题；
2. 记录实际请求 URL、状态码和响应体；
3. 区分网络层、路由层、参数层和业务数据层错误；
4. 每次修复后保留测试输入和结果，不能只写“已修复”。
